# SimulationCameraControl

Smooth-interpolation camera controls (zoom, orbit, pan) with input auto-binding from DefaultInputMapping.

## Part of ProjectTheForge

This plugin is a git submodule of [ProjectTheForge](https://github.com/tsfarizi/ProjectTheForge), the main Unreal Engine 5.8 project that aggregates all 9 plugins via \.gitmodules\. For the full architecture, see the [ProjectTheForge README](https://github.com/tsfarizi/ProjectTheForge#readme).

## Development

Plugin-local builds (e.g. for unit tests or stand-alone inspection) can be done from this directory once the project is fully cloned and the \.uproject\ is regenerated. The main project itself is built from the top-level ProjectTheForge directory.
